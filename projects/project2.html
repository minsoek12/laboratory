RF Circuit Simulator (Level 1)

RF simulator level1은 python을 베이스로 간단한 상황에 대한 circuit block단위 분석이다.

Project Overview

This project implements a simplified RF system simulator using Python. RF components are modeled as two-port networks and cascaded to evaluate system-level performance.

Model Assumptions

  • 50Ω reference impedance
  • Two-port network RF modeling
  • Frequency sweep analysis
  • Analytical gain and noise modeling

Simulation Result

Key Features

  • Frequency dependent gain simulation
  • Noise figure calculation
  • RF network cascade modeling
  • Object-oriented Python architecture
