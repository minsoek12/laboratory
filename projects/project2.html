RF Circuit Simulator (Level 1)

Python-based RF circuit simulator developed for analysis of gain, noise figure, and impedance behavior in RF amplifier chains.

Project Overview

This project implements a simplified RF system simulation framework using Python. The simulator models RF components as two-port networks and evaluates system-level performance such as gain and noise figure across frequency.

Model Assumptions

  • Two-port network based system modeling
  • 50Ω reference impedance
  • Frequency sweep simulation
  • Gain and noise behavior modeled analytically

Simulation Result

Key Features

  • Frequency dependent gain simulation
  • Noise figure calculation
  • Network cascade modeling
  • Python object-oriented RF block modeling
